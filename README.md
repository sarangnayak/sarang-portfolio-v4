## Project Overview

This repository contains the source code for a personal portfolio website built to showcase full-stack and AI engineering work. It is designed for recruiters, collaborators, and clients to quickly understand the developer's technical range, past projects, and areas of focus.

The site highlights four core competency areas:

- **Full Stack Development** — maintainable web applications across frontend, backend, and data layers.
- **Applied AI** — practical AI features built around real application requirements.
- **Backend & System Design** — reliable APIs, data models, and services.
- **AI-Assisted Engineering** — using AI to accelerate development without compromising quality.

---

## Key Features

- **Selected Works Section** — showcases projects from 2024–26 with clear navigation.
- **Capability Breakdown** — four structured areas: full stack, AI, backend/system design, and AI-assisted engineering.
- **Contact Interface** — form for project briefs and collaboration inquiries.
- **Responsive Layout** — designed for desktop and mobile viewing.
- **Static Deployment** — hosted on GitHub Pages for fast, reliable delivery.
